# cosmic-dorito.github.io

Personal engineering portfolio — https://cosmic-dorito.github.io

Static single-page site (hash-routed, no build step). Six case studies covering distributed
edge scheduling, physics-informed thermal reconstruction, an ROV and optical link built at
NIOT, an LLM patent-intelligence pipeline, bearing fault diagnosis, and analog filter design.

Every figure on the site traces to a project report, paper, poster, or synthesis log.
